# Madhav K. - Personal Portfolio

Welcome to the official repository of my personal portfolio website. This project showcases my skills, projects, and experience as a graphic designer, video editor, and web developer.

## About Me

I'm Madhav K., a creative professional based in Jaipur, India, with a passion for crafting designs that tell meaningful stories, spark emotion, and leave a lasting impact. From digital experiences to visual identities and illustrations, I blend creativity with precision in every detail I create.

## Features

*   **Responsive Design:** The portfolio is fully responsive and looks great on all devices, from mobile phones to desktop computers.
*   **Modern UI/UX:** A clean, modern, and intuitive user interface with smooth interactions and a polished aesthetic.
*   **Project Showcase:** A dedicated section to showcase my projects with details, images, and links.
*   **Services:** An overview of the services I offer, including branding, creative development, video editing, and social media management.
*   **About Me:** A detailed section about my skills, experience, and creative philosophy.
*   **Contact Form:** A functional contact form to get in touch with me.

## Tech Stack

*   **Frontend:** HTML5, CSS3, JavaScript
*   **Libraries & Frameworks:** GSAP, Swiper.js, Lenis, Typed.js
*   **Design Tools:** Photoshop, Illustrator, Premiere Pro, After Effects, Affinity, Figma

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You'll need a web browser to view the website.

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/Madhavk005/MadhavK-Portfolio.git
    ```
2.  Open the `index.html` file in your browser.
